# 校时及启动恢复复查

- 从 MU300 维护分支同步校时顺序：原默认四个 pool 域名配置不变，先尝试
  IPv4/IPv6 数字端点，最多 20 秒；失败后用原域名列表。自定义服务器、DHCP
  增补服务器、停用和服务权限保留，不新增周期守卫。
- 接入实际发布入口 `tools/u30pro-package.py` 的 finish，保留继承构建入口的
  一致行为；重复准备根目录不重复改服务，不读取设备或旧 ZIP 作为源码。
- U30 Pro/F50 Pro 的运行时启动控制默认允许连续失败 6 次，LK 额度为 7，
  第 7 次回到 Android。已有次数设置保留，成功标志不置位，不改按键。
  两款原生 init 保持原样，失败判断仍由 LK 完成，不导入 MU300 软件计数逻辑。
- WCN PR #8 是 SC2355 PCIe 总线生命周期修复，不适用于 Pro 的 AIC8800 SDIO。

离线验证：7 项测试通过，覆盖两种物理槽位的 CRC、非目标字节、原成功位、
自定义次数、IP/DNS 顺序、超时、停止及重复 staging。另核对本机实际 Pro
prepared root 的 sysntpd。未部署或刷机，不能据此宣称实机验收通过。
